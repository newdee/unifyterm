1. 产品定义

uni-term 是一个自带窗口的跨平台终端。它在 Windows、macOS、Linux 上提供同一个界面、同一套命令、同一份历史和同一个 AI 接口。

层谁负责说明
窗口与渲染uni-term（新写，GPUI）字符网格、连字、CJK 与 emoji、输入法、图片、候选列表、AI 卡片、设置。
多窗格与 agent 管理keepane（已有）uni-term 只做标签页。分屏、持久会话、agent 收件箱、MCP 继续由 keepane 提供。uni-term 只读取 agent 状态并显示。
shell系统 shell（托管）Windows 运行 pwsh，macOS 和 Linux 运行 zsh 或 bash。uni-term 注入 PATH 和 shell 钩子。
命令集ut（新写，集成）一个 multi-call 二进制。集成 uutils、ripgrep、jaq；自己写 view、md、explain。默认启用，可整体或逐条切回系统命令。

3. 关键决定与依据

主题决定依据与风险
GUI 框架GPUI 已实测gpui 0.2.2 在本机 Windows 冷编译通过。spike 窗口运行了 PowerShell 7，按键可用，连字已渲染。shape_line(force_width) 支持按网格对齐的连字，paint_image 支持图片，EntityInputHandler 支持输入法。风险 crates.io 上的版本停在 2025-10-22。对策：GPUI 只出现在窗口这一个 crate；M1 结束时评估改为锁定 Zed 仓库的某个提交。
屏幕状态alacritty_terminal 0.26Zed 的终端使用它。它不处理图片协议。对策：在 session 里先拦截 kitty graphics 序列再交给它。备选 libghostty-vt 0.2.2 自带 kitty 模块，M5 前评估。
多窗格不做，交给 keepanekeepane 0.69 已有分屏、持久会话、agent 状态、MCP、OSC 133 钩子。uni-term 重做一遍没有收益。
命令集集成，不重写uutils coreutils 0.11 通过 653 项 GNU 测试，约 22 项失败，MIT 许可。微软 2026 年 6 月发布的 Coreutils for Windows 也基于它。自己重写约 100 个命令要按人年计。
命令集开关PATH 前置 + 配置uni-term 启动 shell 时把 ut 的命令目录放到 PATH 最前，并在 pwsh 里移除 cat、ls、rm 等同名别名。commands.builtin = false 整体关闭；commands.system = ["curl"] 逐条切回。
历史检索SQLite FTS5 + 重排纯 BM25 有两个问题。第一，输入到一半的词（gi）匹配不到 git，需要前缀或 trigram 匹配。第二，BM25 会降低高频词的权重，而历史里高频命令应该排前。做法：FTS5 负责召回，排序 = 文本匹配分 + 使用频率和新近度 + 当前目录 + 退出码。
候选列表位置终端层（GUI）VS Code 和 Windows Terminal 用同样的做法：shell 钩子报告提示符位置和命令行文本，终端画候选。这样对所有 shell 生效。
AI接口 + 可换后端建议用灰色文字显示，不阻塞输入。纠正和解释都用弹窗显示在输入行旁边，不留在滚动记录里。纠正在命令失败后出现：Enter 把修正后的命令填入输入行，Esc 关闭。解释由 Ctrl-Shift-E 唤出：Enter 或 Esc 关闭。弹窗里的 Enter 不运行命令。解释优先用本地帮助数据，再问模型。隐私 命令行可能含密钥。发送前脱敏，默认需要用户开启。
图片与视频ut view 自动降级见第 4 节。视频解码依赖 ffmpeg，纯 Rust 没有覆盖 H.264/H.265 的成熟解码器。
markdownut md + GUI 原生ut md 在任何终端输出带样式的文本，图片走 view 的降级链，做法同 glow、mdcat。nvim 的 render-markdown.nvim、markview.nvim 用隐藏文本和虚拟文本在编辑器里渲染；image.nvim 用 kitty graphics 显示图片，uni-term 支持该协议后它可直接工作。AI 卡片在 GUI 里原生渲染 markdown。
字符集全程 UTF-8按字素簇计算宽度（CJK、emoji 组合）。字体回退链：等宽主字体 → CJK → 彩色 emoji → Nerd Font 符号。制表符和 Powerline 符号由程序自己画，保证拼接无缝。旧编码用 ut iconv 转换。

4. 在终端里显示图形：7 种方式

ut view 启动时探测终端能力，从上到下选第一个可用的方式。演示页里关闭"图形界面"开关可以看到后几种。

方式每格像素支持的终端说明
kitty graphics真实像素uni-term、kitty、Ghostty、WezTerm、Konsole、iTerm2功能最全：真彩色、透明、动画帧、按 id 复用图片。它的 Unicode 占位符模式可以穿过多路复用器，keepane 里显示图片要用这个模式。
iTerm2 内联图片真实像素iTerm2、WezTerm、VS Code一条 OSC 1337 序列带 base64 文件。实现最简单，没有动画控制。
sixel真实像素Windows Terminal 1.22+、foot、xterm、WezTerm1980 年代的协议，调色板最多 256 色，体积大。kitty 和 Ghostty 拒绝支持。
半块字符 ▀1×2所有支持真彩色的终端前景色画上半格，背景色画下半格。chafa、timg、viu 的默认回退。
六分块、八分块2×3、2×4字体含 Unicode 13 或 16 相应字符的终端每格只有 2 种颜色，分辨率更高，边缘更清楚。
盲文点阵 ⣿2×4几乎所有 Unicode 终端每格 1 种颜色。适合线条图和单色画面。
ASCII约 1×2全部按亮度选字符。最后的回退，纯文本日志里也能看。

没有任何终端模拟器时（Linux 文本控制台），程序可以直接写 framebuffer 或 DRM/KMS，mpv 的 --vo=drm 就是这样播放视频。这条路只在 Linux 可用，列为以后的可选项。

5. 里程碑

阶段内容验收标准
M0 完成技术验证：窗口 + pty + 屏幕文字 + 按键。9 项单元测试通过；窗口截图显示 PowerShell 提示符和回显。
M1 终端基础按格定位的网格渲染（颜色、粗斜体、光标、选择、复制粘贴、回滚、鼠标上报）、输入法、字体回退、连字开关、标签页、配置文件。vim、htop、keepane 显示正确；Windows 上用拼音输入法输入中文成功；vttest 的光标和滚动项通过。
M2 命令集 已验收ut multi-call 二进制、PATH 注入、别名移除、整体和逐条开关。Windows 上路径一律显示为 /（UT_NATIVE_PATHS 可恢复 \）；通配符 *.txt 像 Unix shell 一样展开，加引号则保持原样。同一组夹具文件上，Windows 与 Linux 的 cat ls grep find sed jq sort 等输出逐字节一致；开关切换后 which cat 结果改变。
M3 历史与候选 已验收shell 钩子（pwsh、zsh、bash、fish）、history.db、候选列表、Ctrl-N/P 和方向键。10 万条历史下，单次查询 p95 低于 5 ms；失败的命令排在成功的之后；含密钥模式的命令不入库。
M4 AI 已验收建议、纠正、解释；后端配置；脱敏。无网络时终端全部功能照常，AI 功能安静地不可用；脱敏测试集 100% 命中。
M5 图形与 markdownGUI 支持 kitty graphics；ut view 降级链；ut md。同一张图在 uni-term、Windows Terminal、纯文本管道里各自选对方式；image.nvim 在 uni-term 里显示图片。
M6 agent 接口agent 侧栏（读 keepane）、ut mcp、skill 文件。Claude Code 通过 MCP 查询历史并得到结果；skill 让 agent 在 Windows 上直接使用 cat、jq。
M7 视频与发布视频播放；MSI 与 winget、Homebrew、deb 与 AppImage；macOS 和 Linux 实机验证。三个平台各有一个可安装包；同一份配置和历史文件在三个平台可用。
自己的 shell 挂账统一三个平台的 shell 语法。两条路线：嵌入 brush（bash 兼容，约一个里程碑），或从零写（以年计）。先不做，以后再定。方案和通过线保留在 docs/plan.md 末尾。

6. 待你决定的问题

问题我的建议
"统一"是否包含 shell 语法 重要托管系统 shell 时，Windows 写 $env:FOO = 1，Linux 写 export FOO=1。命令统一了，语法没有统一。建议 M2 之后评估内置一个 bash 兼容 shell（brush），作为可选的统一默认。
keepane 里的候选列表在 keepane 里运行时，shell 的 OSC 133 标记被 keepane 消费，uni-term 看不到提示符位置。建议在 keepane 加一个小功能：把当前窗格的标记转发给外层终端。
默认是否启动 keepane建议默认直接启动 shell。在设置里提供"新标签页运行 keepane"。
默认模型后端建议不设默认。第一次使用 AI 功能时让用户选择并说明哪些文本会发送出去。
是否开源及许可keepane 是 MIT。建议 uni-term 也用 MIT。herdr 是 AGPL：可以参考设计，不能复制代码。
